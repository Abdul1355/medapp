# Frontend
Expo Router app targeting web, Android and iOS.

Install dependencies with `npm install`, copy `.env.example` to `.env`, then run `npx expo start`. The app detects the API host automatically from the Expo dev server. If auto-detection cannot reach your computer, set `EXPO_PUBLIC_API_URL` in `.env` to its LAN address, such as `http://192.168.1.20:8000`.
